# Changelog

All notable changes to Structio are documented in this file.

The format is based on Keep a Changelog,
and this project follows Semantic Versioning.

## [1.0.0] - 2026-08-13

### Added

- Reusable website architecture profiles.
- Support for 10 website types:
  - Landing Page
  - SaaS
  - Agency
  - Portfolio
  - Ecommerce
  - Travel
  - Wellness
  - Fintech
  - Technology
  - Fashion
- Support for single-page and multi-page architectures.
- Catalog-driven architecture generation.
- Website topology support:
  - Sequential
  - Hierarchical
  - Matrix
- Runtime template model.
- Collection and entry-point template references.
- Semantic domain validation.
- Architecture graph generation.
- JSON serialization.
- JSON deserialization and round-trip support.
- CLI generation command.
- CLI options for site type, mode, and output path.
- Comprehensive test coverage across the full 20-combination matrix.

### Validation

- 326 tests passing.
- All 20 site type/mode combinations validated.
- Generation, validation, serialization, round-trip, and CLI flows verified.
